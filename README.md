# Tarun Jampani — Personal Portfolio & Technical Showcase

A long-scrolling, high-performance web portfolio highlighting projects, certifications, technical skills, interactive terminal environment, and engineering contributions by **Tarun Jampani** ([@tarun1790](https://github.com/tarun1790)).

## 🚀 Key Features

- **Ambient Particle Constellation**: Interactive HTML5 Canvas background with dynamic physics and node connection lines.
- **Interactive Developer CLI Terminal**: Live interactive terminal with commands like `neofetch`, `skills`, `projects`, `certs`, `contact`, `whoami`, and `quote`.
- **GitHub Projects Showcase**: Dynamically populated project grid highlighting 14 open-source repositories with real-time category filtering (AI & Machine Learning, Systems & Security, Software & Web) and search bar.
- **Certifications Showcase & Upload Modal**: Highlighted technical credentials with interactive verification modals linked to LinkedIn certifications and dynamic certificate upload capability.
- **Technical Skills Matrix**: Categorized tech stack grid featuring proficiency indicators across Languages, Frameworks, AI/ML tools, Systems, and Security.
- **Responsive Dark Glassmorphism Design**: Custom CSS design system with backdrop blur filters, cyber neon accents, sleek typography, and mobile drawer navigation.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom Glassmorphic System)
- **Typography & Icons**: Google Fonts (Inter, Outfit, Fira Code), Font Awesome 6
- **Data Engine**: JSON Datasets (`data/projects.json`, `data/certifications.json`)

## ⚡ Quick Start

You can view the site locally by opening `index.html` in any web browser, or running a simple local development web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx http-server
npx http-server -p 8000
```

Then visit `http://localhost:8000`.
